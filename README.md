# 🏛️ Nagrik Setu

**Nagrik Setu** is an AI-powered municipal citizen grievance intake, triage, and redressal platform.

## 🚀 Key Features
- **4-Tier Role Portals**: Citizen, Govt Official (Higher/Zonal), Govt Official (Ground/Field), and Municipal Administrator.
- **Multi-Municipality Selector**: Out-of-the-box support for TMC, BMC, PMC, NMMC, KDMC, and NMC.
- **Automated AI Triage**: Automatic 1-sentence complaint summarization and multi-factor urgency priority calculation.
- **GIS Heatmap & Map Integration**: Interactive pin-drop complaint lodging and municipal GIS hotspot heatmaps.

## 📂 Quick Start
1. Extract all files.
2. Open `index.html` in any modern web browser or serve it using Live Server.
